# Running an event

Open Admin and pick the event. The steps stay in order. Each change saves immediately. There is no separate draft to remember.

1. **Who is playing.** Check the players who are coming and mark who has paid. The field holds 120 players.
2. **Flights.** Sort by points to make, or move a player by tapping their name and then the flight.
3. **Pairings.** Build groups, start from blank groups, or import a CSV with `group` and `player` columns. Groups post to the public pairings page when you save them.
4. **Scores.** Enter Stableford scores. WD marks a withdrawal. Save scores when the card is ready. You can enter scores before pairings exist.
5. **Review.** Read the checklist. Season points are added to what players already have. Players who did not play keep their points.
6. **Publish.** Confirm. A snapshot is saved first. History can put the roster and season points back.

Roster holds names, tees, points to make, phones, credit, the beginning-of-year list, and the button that clears season points for players under 7 rounds. That button updates both the public standings and the points record.

Downloads make the PDFs and spreadsheets. Accounts add or disable board admins.

Practice mode (`npm run dev:seed`) uses sample players in the browser only. The gold banner means nothing is written to the live site.
